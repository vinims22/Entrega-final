## 📝 Descrição do Projeto

O objetivo deste aplicativo é permitir que os usuários **pesquisem**, **listem** e **visualizem** informações sobre Digimons consumindo a **DigiAPI**.

O projeto foi construído com foco em:
- Arquitetura **Monorepo**
- Aplicação **PWA** totalmente instalável
- Workflow de **CI/CD automatizado** com GitHub Actions
- Boas práticas de performance (validadas com Lighthouse)
- Deploy via GitHub Pages
